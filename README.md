# Shabnam Yasmin — Creative Portfolio

Responsive single-page portfolio using plain HTML, CSS and JavaScript.

## AI-Assisted Design & Development

This portfolio was developed through an iterative AI-assisted workflow
using ChatGPT and prompt engineering.

The process involved multiple rounds of:
- Visual direction and layout planning
- Portfolio structure and content organization
- HTML/CSS development
- Responsive layout refinement
- Image composition and visual selection
- Debugging and UI adjustments
- Iterative prompt-based revisions

## Iterative Design Process

The portfolio went through 13+ iterations. Each iteration was reviewed
against my intended visual direction and refined based on design,
content and usability requirements.

During the process, I:

- Replaced mismatched placeholder images and names
- Selected and organized my own portfolio work
- Adjusted image positioning, proportions and cropping
- Refined colour combinations and contrast
- Modified typography and visual hierarchy
- Corrected spacing and alignment issues
- Refined responsive behaviour across screen sizes
- Reviewed and revised individual sections rather than accepting
  generated layouts as-is

The final version was selected and further curated by me to match
the intended visual direction, content and responsive behaviour.
